# NHL Analytics
PET-Проект реляционной базы данных для хранения истории НХЛ, анализа статистики и подготовки данных для обучения моделей по прогнозирования победителя матча.

## Возможности

- Реляционная модель с разделением команд, игроков, тренеров, матчей и событий.
- Ключи, ограничения, индексы и SQL-представления для работы с данными.
- Хранение версий изменяемых сведений и фактов без перезаписи истории.
- Загрузка результатов, участия игроков, голов, передач и послематчевых буллитов.
- Сохранение исходных ответов NHL, проверка их хешей и журналирование загрузки.
- Последовательная загрузка сезона с сохранением прогресса и повторной обработкой ошибок.
- Тесты обработчиков данных, включая проверки на сохранённых ответах NHL.

## Текущий результат

Загружен и проверен сезон **2023/24**: **1400 завершённых матчей**. Для всех матчей подтверждено покрытие результатов и событий, расхождений между количеством голов и официальным счётом не обнаружено.

Модель машинного обучения пока не обучена.

## Технологии и структура проекта

PostgreSQL 17, Docker Compose, Python 3.12, psycopg, requests, python-dotenv, unittest.

Описание модели: [docs/model.md](docs/model.md). Диаграммы: [docs/diagrams](docs/diagrams).

## Запуск загрузки

Команды выполняются из корня проекта. Для загрузки нужна база с применёнными скриптами из `sql/migrations/`.

Создать `.env` по образцу `.env.example` и указать пароль PostgreSQL.

```bash
sudo docker compose up -d db
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Проверка загрузки на трёх матчах:

```bash
python scripts/load_season.py 20232024 --limit 3
```

Загрузка оставшейся части сезона:

```bash
python scripts/load_season.py 20232024 --all
```

Повторный запуск проверяет и пропускает успешно обработанные матчи. Для повторного получения всех матчей, включая уже загруженные, используется `--all --refresh`. Прогресс сохраняется в `data/jobs/season_20232024.json`.

Запуск Python-тестов:

```bash
python -m unittest discover -s scripts/tests
```
